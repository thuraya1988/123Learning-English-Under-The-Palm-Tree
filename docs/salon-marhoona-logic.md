# منطق لعبة صالون مرهونة

> ورقةُ عملٍ لكِ. كلُّ ما فيها مقروءٌ من الشفرة نفسِها لا من الذاكرة،
> ومعه رقمُ السطر لتصلي إليه مباشرةً.
>
> **الملفّ:** `salon-marhoona.html` (وكان اسمُه `saloan-marhoona-new.html`)
> **وأخوه:** `salon-marhoona-3d-room.html` — اللعبةُ نفسُها، لكنّها تفتح
> داخلَ الغرفة ثلاثيّةِ الأبعاد وشاشتُها خلفَ زرّ ☰.

---

## ١) الفكرة في سطر

مرهونةُ معلّمةٌ في قرية القرواشية بسمائل سنةَ ١٩٧٣، تعلّم الطالبةَ
**طقوسَ الجمال العُمانيّ**. كلُّ طقسٍ درسٌ في الإنجليزيّة: مفرداتُه
وقاعدتُه وحكايتُه.

## ٤) شكلُ الطقس الواحد

`RITUALS` — السطر **428**. وهذا كلُّ حقلٍ فيه وما يفعله:

```js
{
  id: 1,                    // رقمُه — ولا يتكرّر
  coll: 1,                  // إلى أيّ مجموعةٍ ينتمي (١–٥)
  name: 'The Morning Rosewater',   // اسمُه بالإنجليزيّة
  ar: 'ماء الورد الصباحي',          // وبالعربيّة
  ico: '💧',                // رمزُه (أو وسمُ <img> لصورة)
  subtitle: 'Guest hospitality',   // سطرٌ صغيرٌ تحت الاسم

  ingredients: ['rosewater','cardamom'],   // ← مرحلةُ الاختيار
  greeting: 'Good morning, dear student…', // ← ما تقوله مرهونة أوّلًا

  steps: [                  // ← أربعُ خطوات، لا أكثرَ ولا أقلّ
    { inst: 'Take the glass bottle of rosewater from the shelf.',
      actions: [ {t:'Pour rosewater', c:1},   // c:1 = الصحيح
                 {t:'Light bukhoor',  c:0},   // c:0 = خطأ
                 {t:'Grind saffron',  c:0} ] },
    …
  ],

  ritual: 'rosewater_pour', // ← اسمُ الحركة المرئيّة (انظر ٦)
  naming:  'Pronounce: "The Morning Rosewater"',   // مرحلةُ النطق
  lesson:  'This ritual is performed every morning…', // الدرس
  vocab: [ {en:'Rosewater', ar:'ماء ورد'}, … ],    // ← ثمانُ كلمات
  grammar: 'Imperative: "Pour the rosewater gently."',
  lore:    'When Thuraya\'s grandmother was young…'  // حكايةُ القرية
}
```

**قاعدتان ثابتتان في كلّ الطقوس التسعةَ عشرَ:** أربعُ خطواتٍ، وثمانُ
كلمات. وإن أردتِ خمسَ خطواتٍ أو عشرَ كلماتٍ فالشفرةُ تحتملها — العدُّ
مأخوذٌ من طول القائمة لا من رقمٍ مكتوب.

## ٥) رحلةُ الطقس — سبعُ مراحل

`renderPhase` — السطر **1302**. وشريطُ التقدّم أعلى الشاشة يقرأ منها:

| المرحلة | ماذا يحدث | التقدّم |
|---|---|---|
| `greeting` | مرهونةُ تُرحّب وتقول ما سنصنعه اليوم | ٠٪ |
| `ingredients` | الرفُّ فيه المكوّناتُ التسعةُ مخلوطة، تختار الطالبةُ ما يخصّ هذا الطقس | ١٥٪ |
| `mixing` | الخلط | ٣٥٪ |
| `ritual` | **الخطواتُ الأربع** — في كلِّ خطوةٍ ثلاثةُ خياراتٍ وواحدٌ صحيح | ٦٠٪ |
| `naming` | تنطق الطالبةُ اسمَ الطقس بالإنجليزيّة | ٨٠٪ |
| `lesson` | الدرسُ والكلماتُ الثمانُ والقاعدةُ والحكاية | ٩٠٪ |
| `done` | النجومُ والاحتفال | ١٠٠٪ |

## ٦) الحركاتُ المرئيّة

الحقلُ `ritual` يختار ما يُرسَم على الشاشة. والمتاحُ اثنتا عشرة:

`rosewater_pour` · `bukhoor_smoke` · `hand_wash` · `scalp_oil` ·
`hair_wash` · `body_oil` · `foot_soak` · `face_mask` · `henna_trace` ·
`saffron_milk` · `baby_massage` · `wedding_bukhoor`

**لطقسٍ جديد:** اختاري واحدةً منها. وإن أردتِ حركةً جديدةً فهي شفرةٌ
تُكتَب، قولي لي أيَّ حركةٍ تريدين.

## ٧) النجوم — كيف تُحسَب

`finishRitual` — السطر **1884**

```
المجموع = (دقّةُ المكوّنات × ٠٫٤)
        + (دقّةُ الخطوات   × ٠٫٣)
        + (النطق          × ٠٫٣)

٠٫٩ فأكثر → ٣ نجوم    ٠٫٦ فأكثر → نجمتان    دون ذلك → نجمة
```

> ### ⚠ ثانيًا: النطقُ يأخذ ٣٠٪ بلا قياس
> `pronScore = 1` — مكتوبٌ ثابتًا، ومعه تعليقٌ في الشفرة يقول
> *«مبسَّط: امنحها العلامةَ كاملةً إن وصلت إلى هنا»*.
>
> فثلاثون بالمئةِ من الدرجة تُمنح دائمًا. وأثرُ ذلك أنّ من يخطئ في
> المكوّنات كلِّها وفي الخطوات كلِّها يخرج بنجمة، ومن يصيب المكوّنات
> ويخطئ نصفَ الخطوات يخرج بثلاث.
>
> والحلُّ إمّا أن نقيس النطقَ فعلًا (المتصفّحُ يسمع)، وإمّا أن نوزّع
> الثلاثين على المكوّنات والخطوات. قولي أيَّهما.

**والتقدّم** يُحفَظ في المتصفّح تحت `palm_marhoona_progress` — رقمُ
الطقس ← عددُ نجومه.

## ٨) لا شيءَ مقفل

`showLevelSelect` — السطر **1196**. الطقوسُ كلُّها مفتوحةٌ من أوّل
لحظة، والقفلُ موجودٌ في التنسيق (`.level-btn.locked`) ولا يُستعمَل.

فإن أردتِ التدرّج — لا يُفتح الثاني إلّا بعد الأوّل — فهو سطرٌ واحد.
وإن أردتِ بقاءَها مفتوحةً على مزاج الطالبة فهي كذلك الآن.

## ١٠) خلاصةُ ما ينتظر قرارَك

| # | الأمر | الخيارات |
|---|---|---|
| ١ | **١٩ طقسًا لا ٣٦** | نكتب السبعةَ عشرَ الباقية · أو نُصحّح الرقمَ المعلَن |
| ٢ | **النطقُ ٣٠٪ بلا قياس** | نقيسه بالميكروفون · أو نوزّع درجتَه على البقيّة |
| ٣ | **لا تدرّجَ في الفتح** | نُقفل حتى يُنجَز ما قبلَه · أو نُبقيها مفتوحة |
| ٤ | **حركاتٌ جديدة** | اثنتا عشرة متاحة — أيَّ حركةٍ تريدين زيادةً؟ |

## ١١) أين تكتبين طقسًا جديدًا

في `salon-marhoona.html` بعد السطر **428**، انسخي أيَّ طقسٍ وغيّري
حقولَه. ولا يلزم شيءٌ غيرُ ذلك: الشاشاتُ والعدّاداتُ والمجموعاتُ
كلُّها تقرأ من القائمة نفسِها.

> والتعديلُ يُكتَب مرّتين: في `salon-marhoona.html` وفي
> `salon-marhoona-3d-room.html` — فالملفّان يحملان النسخةَ نفسَها من
> الطقوس. وإن شئتِ جعلتُهما يقرآن من ملفٍّ واحدٍ مشترَك فلا يُكتب
> الطقسُ إلّا مرّة، كما فعلنا في ألغاز القلعة.
