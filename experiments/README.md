# Experiments

Standalone side-projects, unrelated to the Under the Palm Tree platform.
Kept here for backup/archiving only — each folder is self-contained.

- **leo-live/** — Real-time LEO satellite tracker (Vite + React + Three.js +
  satellite.js, CelesTrak TLE data, SGP4 propagation). See `NOTES.md` inside
  — a few files needed to actually build/run it were not part of this
  upload.
- **open-sea/** — Standalone WebGPU ocean renderer (Three.js TSL, no build
  step, open `index.html` directly).
- **silk-atlas/** — "Silk Atlas" interactive showcase page. Includes the
  full original development bundle (spec, planning notes, test scripts,
  QA screenshots) as-is, not just the deliverable.
- **gargantua/** — Schwarzschild black hole raytracer (vanilla JS + vendored
  Three.js, real-time GLSL raytracing).
