# مس ثريا — معلّمة الإنجليزيّة للصفّ الخامس

روبوت محادثة عربيّ مخصّص **حصراً** لمنهج الصفّ الخامس في سلطنة عُمان —
كتاب النشاط `OMAN 5A Activity Book` (Team Together، الطبعة الأولى ٢٠٢٦).

## النسخ

- `index.html` — النسخة الكلاسيكية: دماغ محلي + وضع ذكي للأسئلة الحرة.
- `v2.html` — **Tutor V2**: واجهة متكيفة بمستويات دعم/متوسط/متقدم، وأوضاع شرح/اختبار/تصحيح/تلميح، وذاكرة جلسة واقتراحات متابعة وملخص مهارات محلي.
- `api/ask.js` — Tutor V2 API متوافق مع الواجهة القديمة والجديدة.

## ماذا يفعل Tutor V2

- يميّز تلقائيًا بين **الشرح، الحل، التصحيح، التلميح، الاختبار، والمفردات**.
- يغيّر مستوى الشرح بحسب مسار الطالبة: `support` / `intermediate` / `advanced`.
- يحافظ على سياق آخر الرسائل حتى يستطيع متابعة سؤال سابق أو تصحيح إجابة اختبار.
- يرسل مع كل إجابة بيانات عن الوحدة والمهارة ونوع الطلب لاستخدامها لاحقًا في لوحة متابعة الطالبات.
- لا يستهلك طلب AI عند فحص الاتصال `ping`.
- يمنع اختلاق صفحات أو أرقام تمارين أو إجابات كتاب لم يتم تزويده بها.
- يطلب صورة السؤال أو نصه عندما يحتاج محتوى لا يراه.

## وضعان

1. **وضع الكتاب** في `index.html` (يعمل دائمًا بلا تكلفة) — دماغ محلي يحفظ المنهج.
2. **Tutor V2 الذكي** — للأسئلة الحرة والتدريب المتكيف. يُفعّل بمتغيّر البيئة:

   ```
   ANTHROPIC_API_KEY = sk-ant-...
   ```

   ويمكن اختياريًا تحديد الموديل عبر:

   ```
   ANTHROPIC_MODEL = claude-opus-5
   ```

   في Vercel → Settings → Environment Variables، ثم إعادة النشر.
