# 🌴 Under Palm Tree Village - قرية النخلة

لعبة 3D تعليمية تفاعلية مبنية على رواية Under Palm Tree والتراث العماني.

## 📁 محتويات الملف

- `index.html` ← ملف اللعبة الرئيسي (افتحه في أي متصفح)

## 🚀 كيف تلعب

### على الكمبيوتر:
1. افتح ملف `index.html` في أي متصفح (Chrome, Firefox, Safari)
2. استخدم الأسهم للتحرك
3. **اسحب الماوس** للنظر حولك
4. **انقر** على المكعبات لحفرها
5. **اضغط مطولاً** لبناء مكعبات
6. **زر النخيل** → اختر "جذع نخلة" → اضغط مطولاً على الأرض

### على الجوال:
1. افتح الملف في Safari/Chrome
2. استخدم أزرار التحكم في الأسفل
3. **اسحب الشاشة** بإصبع واحد للنظر حولك
4. **انقر** على الشاشة لحفر/بناء

## 🚀 رفع اللعبة على الإنترنت

### GitHub Pages (مجاني):
1. سجّل في [github.com](https://github.com)
2. أنشئ مستودع جديد (New Repository)
3. اسم المستودع: `under-palm-tree-village`
4. اجعله **Public**
5. ارفع ملف `index.html`
6. اذهب لـ Settings → Pages → Branch: main → Save
7. الرابط يصير: `https://yourusername.github.io/under-palm-tree-village/`

### Netlify (أسرع):
1. ادخل [netlify.com](https://netlify.com)
2. سجّل بالـ GitHub
3. اضغط "Add new site" → "Deploy manually"
4. اسحب ملف `index.html`
5. الرابط جاهز فوراً!
