# مس ثريا — معلّمة الإنجليزيّة للصفّ الخامس

روبوت محادثة عربيّ مخصّص **حصراً** لمنهج الصفّ الخامس في سلطنة عُمان —
كتاب النشاط `OMAN 5A Activity Book` (Team Together، الطبعة الأولى ٢٠٢٦).

## ماذا يفعل

- **يشرح القواعد** بالعربيّة مع أمثلة الكتاب نفسه
- **يحلّ الأسئلة** ويشرح القاعدة التي استُعملت
- **يصرّف** أيّ صفة أو فعل فوراً بقواعد الكتاب وتغيّرات إملائه
- **يبحث** في كلمات الوحدات ونماذج الكتابة والأفعال الشاذّة
- **يختبر الطالب** باختبارٍ سريع من أنماط الكتاب

## وضعان

1. **وضع الكتاب** (يعمل دائماً، بلا إنترنت وبلا تكلفة) — دماغ محلّي يحفظ المنهج.
2. **الوضع الذكيّ** (اختياريّ) — للأسئلة الحرّة. يُفعَّل بإضافة متغيّر البيئة:

   ```
   ANTHROPIC_API_KEY = sk-ant-...
   ```

   في Vercel → Settings → Environment Variables، ثمّ إعادة النشر.
   بدونه يظلّ الموقع يعمل بالكامل بوضع الكتاب.

## التشغيل محلّياً

```bash

npx vercel dev
```
