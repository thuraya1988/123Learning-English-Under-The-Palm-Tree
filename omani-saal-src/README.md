# 🎮 الصعل العماني - The Omani Saal

## مغامرات سايبربانك ثلاثية الأبعاد في قلب التراث العماني

---

## 📖 نظرة عامة

لعبة مغامرات ثلاثية الأبعاد تعمل في المتصفح، تجمع بين التراث العماني الأصيل والأسلوب السايبربانك التقني. تتبع قصة **الصعل العماني** — رجل قوي مغوار في خلوق وكريم، يرتدي قميص وبنطلون وشاح علم عمان يتطاير على ظهره.

### قصة اللعبة
> "الصعل العماني — مغوار في خلوق وكريم"

في قرية **القرواشية** العمانية، يعيش الصعل يخدم الناس. يتعلم صناعة الفخار، يخرف النخيل، ويوزع النتاج على الفقراء بالليل.

---

## 🚀 طريقة التشغيل

### المتطلبات
- Node.js (الإصدار 16 أو أحدث)
- متصفح حديث (Chrome, Firefox, Safari, Edge)

### الخطوات

```bash
# 1. تثبيت الحزم
npm install

# 2. تشغيل خادم التطوير
npm run dev

# 3. فتح اللعبة
# افتح المتصفح على: http://localhost:5173
```

### البناء للإنتاج
```bash
npm run build
```

## 🎮 طريقة اللعب

| المفتاح | الوظيفة |
|---------|---------|
| **W, A, S, D / الأسهم** | الحركة |
| **Space** | القفز |
| **Shift** | الجري السريع |
| **E** | التفاعل مع الأشياء |
| **C** | تبديل الكاميرا (ثالثة/أولى) |
| **T** | تسريع الوقت (يوم كامل في ثوانٍ) |
| **R** | تفعيل/إيقاف المطر السايبربانك |
| **Tab** | فتح/إغلاق الخريطة |
| **ESC** | إيقاف مؤقت |
| **الماوس** | تحريك الكاميرا |

### المستويات

1. **إنقاذ عالم الفخار**
   - اذهب إلى ورشة الفخار
   - تعلم خطوات صناعة الفخار
   - وزع الفخار على الفقراء

2. **خرف النخلة**
   - تسلق النخيل
   - اجمع التمر
   - تذكر: النخلة خاصة بنا!

3. **التوزيع ليلاً**
   - تجنب الحراس
   - وزع الهدايا على الفقراء

## 🛠️ التقنيات المستخدمة

- **Three.js** - مكتبة 3D WebGL
- **PBR Materials** - مواد واقعية (Metalness + Roughness)
- **PMREM Environment** - إضاءة محيطية HDRi
- **Unreal Bloom** - توهج نيون سينمائي
- **ACES Filmic Tone Mapping** - ألوان سينمائية
- **PCF Soft Shadows** - ظلال ناعمة
- **Dynamic Fog** - ضباب يتغير مع الليل والنهار
- **Vite** - أداة البناء
