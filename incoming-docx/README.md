# مجلد الوارد — فرغ ولله الحمد

كان هنا أربع ألعاب وصلت كملفات Word، وتحويل Word أتلف كودها.
**خرجت كلّها** بعد إعادة إرسالها خارج الوورد (`.txt` أو لصقًا مباشرًا):

| اللعبة | مكانها الآن |
|---|---|
| أسرار جبل شمس | `jebel-shams-adventure.html` |
| سوق مطرح | `souq-mutrah-palm.html` |
| مينو × داغوص | `meno-dagoos-escape.html` |
| كرتون ميجابوليس | `cartoon-megapolis.html` |

## ما أتلفه Word — للذكرى

| العطب | العدد |
|---|---|
| علامات تنصيص مستقيمة `'` `"` → منحنية | ~21,900 |
| كلمات مفتاحية بحرف كبير (`const`→`Const`) | 1,088 |
| أسماء متغيّرات بحرف كبير في بداية السطر | 539 |
| مفاتيح كائنات بحرف كبير (`map:`→`Map:`) | 108 |
| **حذف كل `:(` بسبب التصحيح التلقائي للوجوه التعبيرية** | **~59 موضعاً** |

العطب الأخير كان فقدان بيانات لا يُستعاد: `{x:(x+.5)*T}` تصير `{xx+.5)*T}`.
ولهذا لم تُصلَح أيّ منها من ملف الوورد، بل أُعيد إرسالها كلّها.

**القاعدة:** أرسلي الملفات بامتداد `.txt` أو `.html` — لا عبر Word.
